# Ant Colonies

A planned relaxing browser sandbox exploring ant foraging and emergent trails through ideas from ant colony optimization (ACO). Ants will initially be drawn as dots, with a basic UI.

The project will start with one colony and click-to-place food. Ants explore and reinforce paths with pheromones. Food does not replenish automatically: food supports population growth, while shortages reduce population. A colony that dies out cannot be revived. Future iterations may add interactive terrain and optimization experiments.

## Status

Planning stage. No application code or runnable development commands exist yet.

Chosen tools: TypeScript and Vite. Proposed renderer: Canvas 2D, running entirely in the browser.
